# Вариативные функции в q: примеры

В репозитории — статья и безопасный воспроизводимый набор примеров. Скрипт выполняет 31 проверку и завершает q с ошибкой при первом несовпадении.

## Запуск

```sh
cd examples
q examples.q -q
```

Проверки подготовлены на q 4.1 от 2025-07-09. Историческое падение несходящейся итерации наблюдалось отдельно на q 4.0 от 2020-10-02; опасный сценарий в набор не включён. Результаты старой сборки нельзя автоматически переносить на другие версии.

`getData3` — учебный пример: он отклоняет неизвестные ключи, но не проверяет полностью типы и структуру значений. В частности, `unassigned` ожидает булевый атом `0b` или `1b`, а `by` — список из двух символов: имя столбца и значение.
